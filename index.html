ข้อมูลเกี่ยวกับ Raspberry Pi (เน้นรุ่น Raspberry Pi 5)

คอมพิวเตอร์บอร์ดเดี่ยว (Single-Board Computer) ขนาดเล็ก ประสิทธิภาพสูง ใช้พลังงานต่ำ เหมาะสำหรับงาน Edge AI, IoT, ระบบฝังตัว และเวิร์กชอปวิศวกรรม

ภาพจำลองบอร์ด Raspberry Pi 5 แบบหมุนได้ 360° & เจาะลึกแต่ละพอร์ต

มุม: 0° • BCM2712
40-Pin GPIO Header 3.3V Logic • Digital / PWM / I2C / SPI / UART

ใช้รับ-ส่งสัญญาณดิจิทัล ควบคุมหลอด LED, มอเตอร์ PWM, เซนเซอร์ และสื่อสารกับอุปกรณ์ภายนอกผ่านโปรโตคอล I2C, SPI และ UART

คำสั่ง/การใช้งาน: pinout
ข้อควรระวัง: แรงดันสูงสุด 3.3V ห้ามต่อไฟ 5V เข้าขา GPIO โดยตรง

CPU & GPU

ใช้ชิป Broadcom BCM2712 Quad-core ARM Cortex-A76 (64-bit, 2.4GHz) และกราฟิก VideoCore VII รองรับการประมวลผลวิดีโอและโมเดล Edge AI ได้ลื่นขึ้น

พอร์ตเชื่อมต่อ & I/O

มีพอร์ต 2x micro HDMI (4Kp60), 2x USB 3.0, 2x USB 2.0, Gigabit Ethernet, PCIe 2.0 x1, พอร์ต CSI Camera และพิน GPIO 40 ขา

ระบบปฏิบัติการ & เซ็ตอัป

นิยมใช้ Raspberry Pi OS (64-bit) หรือ Debian 13 (Trixie) รองรับ picamera2, gpiozero และทำงานร่วมกับหน้าจอหรือ Capture Card ได้สะดวก

ตารางสรุปข้อมูลสำคัญของ Raspberry Pi 5

หมวดหมู่ รายละเอียด ข้อควรระวัง / คำแนะนำ
OS ที่แนะนำ Raspberry Pi OS (64-bit) / Debian 13 (Trixie) เลือก 64-bit เพื่อรองรับ picamera2 และไลบรารีสมัยใหม่
การจ่ายไฟ USB-C 5V / 5A (PD) หลีกเลี่ยงไฟตกเมื่อต่อกล้อง Camera Module 3 หรืออุปกรณ์ USB หลายตัว
ระดับแรงดัน GPIO 3.3V Logic ทุกขา GPIO ห้ามต่อไฟ 5V เข้าขา GPIO โดยตรงเพื่อป้องกันบอร์ดเสียหาย
พอร์ตกล้อง CSI MIPI CSI-2 (ใช้สายแพให้ตรงด้าน) ปลดล็อกคลิปพอร์ตอย่างเบามือก่อนเสียบหรือถอดสายแพกล้อง

คำนวณกำลังไฟชุดอุปกรณ์ (Power Calculator)

กำลังไฟรวมโดยประมาณ: 18W
